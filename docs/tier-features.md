# Tier Features — Pediatra Privato

## Tier Avanzato €4000-6000 | ~740h | ROI 18-24 mesi

Soluzione **telemedicina pediatrica** con triage AI, dosaggio pediatrico AIFA, growth curve OMS e compliance GDPR Art.8.

### 1. **AI Symptom Triage + Telemedicina Aptness**
Ollama classify RED/YELLOW/GREEN suitable-for-telemedicine. Rule-based fallback. ER escalation automation.

### 2. **Dosage Calculator + AIFA Drug DB**
AIFA drug database integration. Formula weight_kg → dose_mg. Interaction check. Age-contraindication alert. Clinical-grade.

### 3. **Growth Curve + AI Centile Prediction**
OMS WHO reference curve. Polynomial regression 6-month trajectory. Failure-to-thrive alert. Pediatra dashboard tracking.

### 4. **Vaccine Scheduler PIV + Reminder**
Italian immunization calendar (PIV). Due reminder SMS. PDF certificate generation. Compliance Ministero Salute.

### 5. **Pre-Visit Screening 24h**
Parent form: history, symptoms, photo rash, vitals. Pediatra pre-visit brief. Reduce in-office time 20%.

### 6. **Post-Visit PDF Note**
Pediatra note + parent-friendly summary. Medication AIFA link. Dosage instructions. Diet recommendation. Download + email.

### 7. **Sick Visit + No-Show Protection**
24h booking window. SMS confirm 12h prior. €20 cancellation fee. Antibiotics prudent-use policy built-in.

### 8. **Parental Consent Workflow GDPR Art.8**
Age-based wizard (child 0-5, 6-13, 14-17). Revocation audit trail. Grandparent custody verification. Compliance-ready.

### 9. **AI Parent Guidance Chat**
Ollama supportive Q&A. When-to-escalate-ER logic. Fever > 39°C → "Consulta pediatra oggi". No medical advice, purely supportive.

### 10. **Growth Projection + Nutrition**
Jenss-Bayley adult height prediction. Ollama nutrition tips (low growth, slow eater). Parent education resource.
